# ALL EUROPE — Language School

Single-page React/Vite website for ALL EUROPE, focused on English and Italian.

## Stack

- React
- TypeScript
- Vite
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project is configured for the custom domain:

https://alleurope.it/

The `public/CNAME` file contains the custom domain.
